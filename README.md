# 破晓守望 · 五大战区

## [▶ 点击开始玩](https://quinn-chen-zikun.github.io/dawnwatch/)

打开网页后，先在主菜单选择「枪战模式」或「剧情模式」，再点击开始。无需登录、下载或安装。

浏览器里的单人第一人称射击游戏。五个战区各有独立地图、灯光、场景道具和路线，可选择标准 8 波或无尽生存。击杀、爆头和通过波次可获得军费，在主菜单的「军械库」购买武器、升级配件并解锁涂装。也可以直接用 `?map=yard|subway|tunnel|hospital|prison` 打开指定战区。

## 两种玩法

主菜单先选择玩法：

- **枪战模式**：原来的波次生存。选择战区后守住标准 8 波，或进入无尽生存。
- **剧情模式**：三人小队战役。你扮演货运港夜班调度员陈默，带着老秦、林夏和小七穿越货运港、地铁站、地下隧道、医院和监狱五个战区，共 15 个阶段。每章分为「推进 / 肃清 / 终局」三个阶段，目标点会以小地图标记和场景光柱指引。队友会跟随、自动射击、被感染者扑倒后等待救援；剧情通过底部字幕和章节过场推进，通关进度保存在浏览器中。

## 剧情模式

02:17，货运港失守。撤离车队将在 05:40 从北岭大桥离开。林夏手里有一份能证明感染源的血样，老秦认得码头的每一条暗路，小七知道穿过封锁线的捷径。你们必须在天亮前穿过五个战区，把样本送上撤离车队。

| 章节 | 战区 | 剧情节点 |
| --- | --- | --- |
| 第一章 · 雨夜集结 | 货运港 | 在南货栈重新集结，找到地铁检修口钥匙 |
| 第二章 · 末班车 | 地铁站 | 穿过停摆列车与月台，绕开封锁闸机 |
| 第三章 · 地下的水 | 地下隧道 | 发现感染通过供水系统扩散，取回泵房记录 |
| 第四章 · 夜班主治 | 医院 | 找到林夏导师留下的研究记录，迎战夜班主治 |
| 第五章 · 破晓之前 | 监狱 | 穿过放风场，死守南区，击败典狱长 |

剧情模式中，队友拥有独立生命值，会跟随玩家走位、自动索敌开火，被击倒后倒地等待救援（靠近即可扶起，时间久了也会自行恢复）。每章军费和通关进度都会保存；通关后可以重玩任意章节。

感染者被击倒后不再直接消失：尸体会向前倒下、在地面停留，随后沉入地面消失；中弹时会溅出血雾与血滴，地面会留下逐渐扩大的血泊。

## 操作说明

也可以用浏览器打开本地的 `index.html` 游玩。

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 | WASD / Shift |
| 瞄准 / 射击 | 鼠标移动 / 左键 |
| 机瞄 / 缩放 | 按住鼠标右键（触屏「瞄准」） |
| 键盘瞄准 / 射击 | 方向键 / 空格 |
| 装填弹药 | R |
| 切换已拥有武器 | 数字键 1–5 / Q 循环 |
| 近战攻击 | F（触屏「近战」） |
| 投掷手雷 | G（触屏「投雷」） |
| 领取补给 | E（靠近标有十字的箱子） |
| 查看战区地图 | M（地图打开时暂停战斗） |
| 暂停 | Esc 或 P |

触屏用左侧摇杆移动，滑动战场瞄准。右侧按钮负责开火、装填、切枪和补给。右上角的「地图」按钮可查看全战区。横屏适合触屏游玩。

## 五大战区

| 战区 | 场景 | 主要区域 |
| --- | --- | --- |
| 雨夜货运港 | 室外雨夜码头，暖冷灯光与湿地反光 | 南侧闸门、中央装卸区、集装箱区、维修站、卸货仓、北侧泵站、南货栈 |
| 地铁站 | 停摆列车、双侧月台与冷白灯管 | 一号站台、二号站台、停摆列车、站厅夹层、换乘通道、列车检修库 |
| 地下隧道 | 断电检修管廊，应急灯与滴水 | 东段 / 西段主隧道、北侧检修室、南侧排水室、中央联络段、深层泵房 |
| 医院 | 白绿色病区、短走廊与病房 | 东侧 / 西侧住院部、门诊走廊、中央护士站、诊疗区、急诊留观区 |
| 监狱 | 高压探照灯下的牢房与放风场 | A 区 / B 区牢房、中央放风场、洗衣房、工场、二号放风场 |

每张地图都是 43 × 43 格，拥有独立的墙体、掩体、补给点和感染者出生点。波次间有 10 秒准备时间，准备期间领取的补给计入下一波。小地图显示当前位置、附近感染者和补给点，南区入口以金色标记。展开战区地图可查看当前位置和朝向、两个南区入口以及各补给点本波是否领取。感染者出生点按实际可行走路线排序，优先选择视线外且路径合理的近处点，并避免连续重复同一处；近距离出生设有下限。

新版用 WebGL 绘制三维丧尸、湿地反光和战区光影，并按战区切换雾气、环境光和灯光布置。丧尸拥有不同的体型、步态、扑击动作和头部命中判定；场景使用混凝土、锈钢和木材的照片材质。浏览器无法使用 WebGL 时，会自动使用 Canvas 渲染。每个战区分别保存最佳波次，音效设置保存在浏览器中。

主菜单可以在标准 8 波和无尽生存之间切换。无尽模式波次持续上升，敌人数量与精英比例逐步提高，每 4 波出现一次暴君；最佳波次会继续累加。

每张地图南侧新增两条可绕行的通路，分别通往南货栈、列车检修库、深层泵房、急诊留观区和二号放风场。每个扩展区有额外补给点、感染者出生点和近距离照明。南货栈有捆扎货箱，列车检修库有检修轨和工具车，泵房有机组和管线，留观区有带护栏的病床，二号放风场有半场线、篮板和训练架。

WebGL 第一人称视角会绘制持枪的手臂、枪械和军械库配件。切枪会切换模型，走动时武器随步伐摆动，开火和装填有独立动作。枪身和手套会受到附近灯光和闪烁影响。

场景里增加了会随战区重建的细节：地铁站有吊顶灯带、长椅、自动售货机和停摆列车的车窗 / 车门；隧道有沿墙管线、阀门、电缆桥架和积水；医院有病房床、隔帘、输液架、担架、轮椅和护士站；监狱有牢房铁窗、床铺、马桶、放风场篮架、探照灯和洗衣房设备。补给箱也会按战区使用不同配色。灯光会轻微闪烁，部分战区在波次开始时触发红色警报，雨夜港口有雨滴涟漪和偶发闪电。每个战区还有独立的环境声：雨声、日光灯嗡鸣、滴水或风声。 玩家移动会发出不同材质的脚步声，附近感染者的脚步会随距离、左右方位和墙体遮挡而变化。

命中沿用枪焰和准星标记；爆头显示橙色「爆头」，击倒显示短暂文字和淡出光环，均不遮挡准星。

## 军械库与军费

击杀感染者、爆头和每波肃清都会获得军费，军费、已购武器、配件等级和涂装保存在浏览器中。

| 武器 | 特点 | 价格 |
| --- | --- | --- |
| K-07 突击步枪 | 初始武器，射速、精度和弹匣均衡 | 已拥有 |
| M-9 手枪 | 初始备用武器，单发伤害高 | 已拥有 |
| V-9 冲锋枪 | 高射速、大弹匣，近距离压制 | ₡ 650 |
| S-12 战术霰弹枪 | 单次 7 枚弹丸，近距离爆发 | ₡ 900 |
| R-7 精确步枪 | 高伤害半自动，爆头收益最高 | ₡ 1,200 |

每把武器有伤害、弹匣、装填、稳定四条配件升级线，升级会直接改变数值，并在枪身上显示瞄具、握把、扩容弹匣和枪口制退器。涂装包括制式、都市迷彩、余烬、极地和霓虹，购买后可随时切换。

军械库底部还有全局装备升级：手雷携行（每级 +1 枚、补给上限 +1）、手雷装药（每级 +15% 爆炸伤害）和防弹护具（每级 -8% 受到伤害）。

基础每局携带 2 枚手雷，补给箱可再补充 1 枚；「手雷携行」升级会同时提高初始携带量和补给上限。手雷会弹跳并延时爆炸，对范围内的感染者造成高额伤害，靠得太近也会伤到自己。

按住右键或触屏「瞄准」可以机瞄：视野拉近、移动变慢，同时显著降低扩散和后坐，适合精确步枪点射和霰弹枪近距离收束。

按 F 或触屏「近战」可以挥击近身敌人，不消耗弹药，带短冷却和轻微击退；换弹时也可以用来应急。

每局结束会显示战斗结算：击杀、爆头、命中率、精英/暴君击倒、近战/手雷击倒、承受伤害和本次军费。

主菜单「设置」可以调整鼠标灵敏度、视野、音量和动态特效；设置会保存在浏览器中，降低视野或关闭动态特效可提升低配设备帧率。

## 感染者类型

主菜单的「感染者图鉴」可以查看每类的首次出现波次和打法。

| 首次出现 | 类型 | 行为 |
| --- | --- | --- |
| 第 1 波 | 普通感染者 | 缓慢追击，靠近后用近战攻击 |
| 第 2 波 | 疾跑者 | 远快于其他类型，要优先处理 |
| 第 3 波 | 盾卫 | 实体盾牌抵挡大部分正面子弹，可以打头或绕侧后 |
| 第 4 波 | 巨化感染者 | 血量和近战伤害最高 |
| 第 4 波 | 自爆者 | 腹部发红光，贴近或死亡时爆炸，优先在远处击倒 |
| 第 5 波 | 喷吐者 | 蓄力起手时锁定酸液方向，趁蓄力横移可躲。墙和货箱也能挡住酸液 |
| 第 6 波 | 尖啸者 | 尖啸只加速能互相看见的附近感染者，短时间提高其移动速度和近战频率 |

第 7、8 波会混合七类感染者。同类喷吐者或尖啸者会错开起手。绿色箭头提示酸液，橙红三角提示尖啸。静音时也能看到预警，墙和货箱会挡住标记。

从第 4 波起，部分感染者会成为**精英**：生命、伤害和移动速度更高，头顶有金色标记、脚下有光环，击倒后获得约 3 倍军费。受击时屏幕边缘会出现红色弧线，指示伤害来自哪个方向。

第 8 波会出现**暴君**：体型更大，近战距离和伤害都高于普通巨化感染者，会蓄力砸地造成范围震荡，顶部有独立血条，击倒后获得大量军费。各战区的暴君有不同名字和数值：南货栈「码头监工」、地铁「末班车长」、隧道「泵房看守」、医院「夜班主治」、监狱「典狱长」。

## 美术参考与材质

- 场景的湿冷光影与近距离丧尸压迫感参考 [《死亡扳机》](https://play.google.com/store/apps/details?id=com.madfingergames.deadtrigger)。丧尸三维模型与动画为本项目制作。
- 照片材质采用 Poly Haven 的 CC0 资产：[受损混凝土地面](https://polyhaven.com/a/damaged_concrete_floor)、[混凝土墙](https://polyhaven.com/a/concrete_slab_wall)、[锈蚀钢板](https://polyhaven.com/a/rusty_painted_metal)、[旧木板](https://polyhaven.com/a/wood_planks)。
- 地铁站的月台灯、应急灯、停摆列车和站厅布局参考 [LAST TRAIN 模块化地铁站套件](https://forums.unrealengine.com/t/souldesignstudio-last-train-stylized-abandoned-subway-station-modular-horror-environment/2846876) 与 [Subway Metro Station 环境资产](https://ultimategameassets.com/assets/subway-metro-station)；应急照明与疏散标识参考 [MTA 车站检查手册](https://www.mta.info/document/16631)。
- 医院的病房床、隔帘、输液架、担架和护士站参考 [PSX Abandoned Hospital](https://assetstore.unity.com/packages/3d/environments/urban/psx-abandoned-hospital-low-poly-ps1-retro-kit-423840) 与 [Hospital Wing](https://assetstore.unity.com/packages/3d/environments/urban/hospital-wing-clean-and-abandoned-418740)。
- 灯光体积感使用屏幕空间光锥与加色光晕，思路参考 [Three.js volumetric beam](https://github.com/TrentSterling/threejs-volumetric-beam) 的圆柱形 billboard 方案，避免逐像素体积光的高开销。
